Suositeltu malli: palvelimella ei luoda erillistä dev@-laatikkoa, vaan osoitteesta tehdään uudelleenohjaus (forwarder) suoraan Gmailiin. Lähetys Gmailista tapahtuu SMTP:llä, jolloin vastaanotto ja lähetys toimivat molemmat samassa pääpostilaatikossa.

1Kirjaudu palvelimen hallintaan (cPanel)

  • Avaa selaimessa https://huolto.fi:2083 (tai palveluntarjoajan hallinnan osoite).
  • Tunnukset: hosting-palveluntarjoajan lähettämät kirjautumistiedot (NetFinn). Jos et tunne niitä, pyydä palveluntarjoajalta cPanel- ja sähköpostitilin tunnukset.

2Uudelleenohjaus: dev@huolto.fi → Gmail

  • cPanelissa valikosta Sähköposti → Uudelleenohjaukset (Forwarders) → Lisää uudelleenohjaus.
  • Osoite: dev  |  Domain: huolto.fi  |  Kohde: jani.malmberg@gmail.com.
  • Valitse "Lähetä sähköpostille edelleen…" ja tallenna. Valmis vastaanotto! — kaikki dev@-posti ilmestyy nyt Gmail-laatikkoosi.
Haluatko myös arkistokopion palvelimelle? Luo ensin oikea laatikko: Sähköposti → Sähköpostitilit → Luo tili: dev@huolto.fi (vahva salasana — tarvitset sitä kohdassa 3). Aseta tilille sisäinen uudelleenohjaus Gmailiin ("Forward All"), jolloin viestit kulkevat YHTÄ AIKAA laatikkoon ja Gmailiin.

3Gmail: lähetä postia nimellä dev@huolto.fi

  • Gmail → hammasratas → Näytä kaikki asetukset → Tilit → osiosta Lähetä postia muilla osoitteilla (Send mail as) → Lisää toinen sähköpostiosoite.
  • Nimi: (esim. "Huoltokello") · Sähköposti: dev@huolto.fi · anna osoite, valitse "Käsittele aliaksena" ✓.
  • SMTP-palvelin huolto.fi · Portti 465 · Salaus SSL (vaihtoehto 587 + STARTTLS) · Käyttäjätunnus dev@huolto.fi · Salasana: palvelimella luodun laatikon salasana.
  • Gmail lähettää vahvistusviestin — se saapuu forwarderin kautta juuri tähän samaan laatikkoon → vahvista koodilla tai linkillä.

4Toimitusvarmuus: DKIM ja DMARC päälle

  • cPanel → Sähköpostin toimitus (Email Deliverability) → huolto.fi-riviltä Enable DKIM (DNS-tietueet lisätään automaattisesti).
  • Suositus lisäksi DMARC: DNS Zone Editor → TXT-tietue: nimi _dmarc.huolto.fi, arvo v=DMARC1; p=quarantine; rua=mailto:jani.malmberg@gmail.com (raportit Gmailiin).

5Testaa (5 min)

  1. Lähetä Gmailista koeviesti itsellesi ja lähetä se Lähettäjä: dev@huolto.fi.
  2. Avaa viesti Gmailissa → Näytä alkuperäinen (Show original) → tarkista SPF: PASS, DKIM: PASS.
  3. Lähetä toinen viesti toisesta sähköpostista osoitteeseen dev@huolto.fi → se ilmestyy Gmailiin ~1 minuutissa.

Lisäosa: alidomain dev.huolto.fi samaan pääpostilaatikkoon

Jos haluat erillisen alidomainin (esim. @dev.huolto.fi) osoitteet samaan Gmail-päälaatikkoon:

  • 1) cPanel → Domains → Create a New Domain/Subdomain: dev.huolto.fi (muut tietueet luodaan automaattisesti).
  • 2) DNS Zone Editor → lisää MX-tietueet alidomainille: dev.huolto.fi. IN MX 0 huolto.fi. → posti ohjautuu samalle palvelimelle.
  • 3) Uudelleenohjaukset: lisää samaan tapaan nimi@dev.huolto.fi → jani.malmberg@gmail.com (cPanel: forwarder per osoite).
  • 4) Gmail: "Lähetä postia muilla osoitteilla" → lisää myös nimi@dev.huolto.fi samalla SMTP-kokoonpanolla (tunnus nimi@dev.huolto.fi).
  • 5) Testaa kuten kohdassa 5.
Tiivistelmä: vastaanotto = cPanel-uudelleenohjaus dev@ → Gmail · lähetys = Gmail "Lähetä postia nimellä" + SMTP huolto.fi:465 (SSL) · alkuperäisyys = DKIM + SPF (valmis) + DMARC · alidomain = sama malli @dev.huolto.fi. Toteutus vie ~10 min.
